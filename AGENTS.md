## Frontend UI/UX guidance

When designing, implementing, reviewing, or changing **visible frontend UI**, read these documents first:

1. [Usage and precedence](ai-skills/00_COMO_USAR_EN_CHATGPT.md)
2. [Taste Skill — ChatGPT adaptation](ai-skills/01_Taste_Skill_ChatGPT.md)
3. [UI/UX Pro Max — ChatGPT adaptation](ai-skills/02_UI_UX_Pro_Max_ChatGPT.md)

Use UI/UX Pro Max primarily for usability, accessibility, component states, navigation, responsive layout, typography, and consistent design tokens. Use Taste Skill primarily for art direction, composition, visual hierarchy, page identity, and appropriate microinteractions.

Respect existing project code, frameworks, dependencies, and design conventions. Treat these guidelines as recommendations rather than instructions to replace requirements. Prioritize correctness, security, accessibility, performance, and user instructions if any guidelines conflict.

For backend-only changes that do not affect UI, these design references are optional.
